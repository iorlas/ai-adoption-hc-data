# Stage 07 — Take-home 2 + feedback

## Take-home (the real transfer moment)

This week, on **one** stored procedure or pipeline you actually maintain:

1. Write a **thin CLAUDE.md** — stack, pointers, conventions, what AI must not touch.
2. Add **one referenced doc** (a data dictionary or glossary for it).
3. Write **one ADR** capturing a decision you've made and an alternative you rejected.
4. Do the **before/after**: run a real question against it before, and again after — note the difference.

Bring the before/after on Wednesday. This is where today stops being a workshop and starts being your
practice.

Once you've built yours, read [`claude-md-best-practices.md`](claude-md-best-practices.md) and **compare
what you did to it** — build first, calibrate second.

## Feedback pulse

Two lines back to me:
- Too basic / about right / want Databricks sooner?
- One thing you'll try on real work this week.

Steers Days 3–4.
