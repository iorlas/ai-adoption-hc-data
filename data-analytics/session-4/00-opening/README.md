# 0 — Opening (15 min)

*No tools. Discussion.*

## Check in on the practice ask

Yesterday's close asked everyone to run one of the two checks — the definition
check or the cross-check — on a real report of their own.

Ask the room. **"I did not get to it" is an acceptable answer and must be
treated as one**, out loud, first, before anyone has to say it. If the first
person to speak gets a reaction, nobody else will be honest.

What to draw out from whoever did try it:

- Did you find a disagreement?
- Was the answer usable, or did it need context Claude did not have?
- What did you have to tell it that we did not have to tell it yesterday?

That last one is the bridge into today: **on your own work, the context is the
work.** The pipeline in `adf/` has no documentation, and the first thing you
will do is build the context that lets anyone — you or Claude — reason about it.

## Reset yesterday's retro into today

Say what you are changing based on last night's feedback, if anything. If the
answer is nothing, say that too, and why.

## Frame the day

Three passes over one pipeline: **understand it, document it, find where it
breaks.** Then a shorter piece on asking better questions of data, and 30
minutes on machine learning that you watch rather than run.

## Say plainly, again

- Everything is synthetic. The pipeline is a teaching artifact, not anyone's
  real pipeline.
- **Nothing today connects to Azure.** No factory, no workspace, no credentials.
  The pipeline is five JSON files on your laptop.
- We are not proposing you stop using the ADF interface. Your words:
  *"it's not that we want to bypass using ADF, it's that we want to make
  ourselves using ADF easier."*
