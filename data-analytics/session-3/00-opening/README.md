## What we cover

**Where July got to.** Two sessions that covered a lot of ground — prompting as
a discipline, Power BI as something you can read and diff, `CLAUDE.md`, Genie,
tokens and context. Today builds directly on the parts you use most.

**What we heard from you since.** The August call reordered this whole plan. In
particular:

- *"ADF is our biggest pain. Everyone hates it."* → most of Tuesday.
- *"Not necessarily how to get AI to make the dashboard, but what would we need
  to do to make sure it was all correct and accurate and appropriate?"* → the
  whole of today's shape.
- *"I would avoid using Python if possible."* → there is no Python content in
  either session. Python is installed only so Claude can run SQL for you.
- *"If we're all using the same data we can show that we get the same output."*
  → one shared dataset, which everyone has loaded.

**How today is shaped.** One question, six parts, each feeding the next. Say
out loud what the day ends with: a definition your team shares, rules that catch
bad data, and a report you can defend.

**The rhythm.** We do it, you do it, you tell us you are ready, we move on. Say
this explicitly, and mean it — the readiness check is not rhetorical.
