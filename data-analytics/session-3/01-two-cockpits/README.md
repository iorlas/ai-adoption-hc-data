# 1 — Same Claude Code, two cockpits (and a prompt refresher)

**12 minutes, hands-on · Claude Code in the terminal and in the desktop app**

## Why this is here

Two reasons, and neither is "the app is better".

**One: it has been a month.** July was two long days and then a gap. This is a
warm-up on something real before the day starts properly, so the first time you
type a prompt is not also the first time you are trying to keep up.

**Two: you were asked to install something you have never used.** July ran in
the terminal. The prerequisites asked for the desktop app. It would be unfair to
ask that and then start the first hands-on exercise assuming you know your way
around it.

## The thing to take away

> **Same Claude Code. Same model, same `CLAUDE.md`, same files. Two windows.**
>
> **For everything in these two days, they are equal.** Every prompt in every
> exercise works identically in both.

We are not going to sell you the desktop app. You will see the same question
answered in both, side by side, and then you pick whichever one you will
actually open. That is the only criterion that matters.

The honest differences — where each is genuinely nicer — are in
[`reference/desktop-or-terminal.md`](../../reference/desktop-or-terminal.md).
The short version: the app lays out file changes better, the terminal gets new
features first, and neither of those will decide anything for you this week.

## The prompt half

The same exercise doubles as a refresher on something that **did** land in July
— the anatomy of a prompt: **request · target · location · actions.** Lucie
played it back accurately at the time, so this is a reminder, not a lesson.

Everything in these two days is written as **plain sentences** — one to three of
them. The four parts are still the four parts; they just live in a sentence.

We start with a deliberately vague prompt, look at the mediocre answer together,
and tighten it as a room. That call-and-response format was the strongest twenty
minutes of July, so we are using it again on purpose.

## What you leave with

The first profile of the shared dataset — which part 2 picks straight up — and a
settled answer to "which window am I working in today".
