# docs/ — the knowledge layer you build this week

Three files here are **skeletons with the headings already in place**, waiting
for you to fill them during the sessions. That is deliberate: writing a document
from a blank page in a twenty-minute exercise is where rooms stall, and the
blank page teaches nothing.

segment.

## Why this folder exists at all, and not just `CLAUDE.md`

`CLAUDE.md` is read on **every single message**. It is a cost you pay
constantly, so it holds pointers and hard rules and nothing else. Everything
with depth lives here, and gets read only when a task needs it.

Get that split wrong and your `CLAUDE.md` is four hundred lines within a month,
every conversation is slower, and nobody reads it.

The sorting drill for which is which:
[`reference/where-knowledge-lives.md`](../reference/where-knowledge-lives.md).

## What a finished version looks like

`templates/example-library/` is a **complete** knowledge layer for a different
organisation — a library service rather than a charity — so you can see the
shape end to end without it handing you the answers to this week's exercises.

Read it after you have built your own, not before. Build first, compare second.
